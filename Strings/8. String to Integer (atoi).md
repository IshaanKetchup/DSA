# 8. String to Integer (atoi)

## Approach: Single Pass / State Flags

The solution processes the string character by character using a single loop. It uses flags to keep track of whitespace, the sign, and the number conversion process.

### Variables

- `res`: Stores the converted integer.
- `whiteFlag`: Determines whether leading whitespace can still be skipped.
- `posi`: Tracks whether the number is positive or negative.
- `signFlag`: Ensures that only one sign (`+` or `-`) is accepted.
- `numFlag`: Intended to track whether a digit has been encountered (currently unused and can be removed).

### Algorithm

**Phase 1: Skip Leading Whitespace**

- Iterate through the string.
- If the current character is a space and `whiteFlag` is `True`, skip it.
- Once a sign or digit is encountered, whitespace is no longer allowed.

**Phase 2: Determine the Sign**

- Check whether the current character is `-` or `+`.
- Only accept a sign if `signFlag` is `0`.
- If the sign is `-`, set `posi` to `False`.
- If the sign is `+`, keep `posi` as `True`.
- Increment `signFlag` to prevent another sign from being accepted.

**Phase 3: Convert Digits**

- If the current character is numeric:
  - Set `signFlag` to `1` to prevent subsequent signs.
  - Set `whiteFlag` to `False`.
  - Update the result using:

  `res = res * 10 + int(i)`

- This shifts the existing number one decimal place to the left and adds the new digit.

**Phase 4: Stop at Non-Numeric Characters**

- If the current character is not numeric, terminate the loop.
- This ensures that only the consecutive digits are converted.

**Phase 5: Handle 32-bit Integer Overflow**

The valid 32-bit signed integer range is:

- Minimum: `-2^31`
- Maximum: `2^31 - 1`

After conversion:
- If the number is negative and falls below `-2^31`, return `-2^31`.
- If the number is positive and exceeds `2^31 - 1`, return `2^31 - 1`.
- Otherwise, return the converted integer with its appropriate sign.

### Complexity Analysis

**Time Complexity: O(n)**

The algorithm iterates through the string at most once, where `n` is the length of the input string. Each character requires constant-time processing.

**Space Complexity: O(1)**

Only a fixed number of variables are used, regardless of the input string length.

### Important Edge Cases

| Input | Output | Explanation |
|---|---:|---|
| `"42"` | 42 | Normal positive integer |
| `"   -42"` | -42 | Leading whitespace and negative sign |
| `"4193 with words"` | 4193 | Stops at first non-numeric character |
| `"words and 987"` | 0 | No initial digits |
| `"0-1"` | 0 | Stops at the second sign |
| `"+-12"` | 0 | Only one sign is allowed |
| `"2147483648"` | 2147483647 | Positive overflow |
| `"-2147483649"` | -2147483648 | Negative overflow |

### Key Observation

The important part of this approach is controlling when whitespace and signs are allowed.

- Whitespace is only valid before the sign or number.
- A sign is only valid before the digits.
- Once digit conversion begins, any non-digit character terminates the conversion.

This allows the algorithm to handle the input in a single pass without using built-in string-to-integer conversion functions.
